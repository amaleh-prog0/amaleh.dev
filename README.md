# Amale Herbert Developer Portfolio

A premium, high-converting developer portfolio designed to market Amale Herbert as a Systems Engineer specializing in Full-stack and AI/ML development.

## 🚀 Tech Stack
- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS (v4)
- **Animations:** Framer Motion
- **Theme:** next-themes
- **Content:** Decoupled TypeScript data files

## 🛠️ Development

### Installation
\`\`\`bash
npm install
\`\`\`

### Run Development Server
\`\`\`bash
npm run dev
\`\`\`

### Production Build
\`\`\`bash
npm run build
npm run start
\`\`\`

## 📂 Content Management
The portfolio is data-driven. To update content, modify the files in the \`data/\` directory:
- \`data/profile.ts\`: Personal info, narrative, and philosophy.
- \`data/projects.ts\`: Project details and detailed case studies.
- \`data/skills.ts\`: Technical stack.
- \`data/experience.ts\`: Professional experience.
- \`data/social.ts\`: Social links and contact info.

## 🎨 Design System
- **Primary Palette:** Near-black / Charcoal foundations.
- **Accent Color:** Electric Cyan (\`#00FFFF\`).
- **Aesthetic:** Monochrome Minimalistic / Editorial.

## 📈 Production Optimization
- Next.js Image Optimization.
- Dynamic Metadata for SEO.
- Responsive layout for all screen sizes.
- Accessibility (A11y) compliant semantic HTML.
